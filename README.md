# AutoCraft

**一键嵌套合成**：背包有全部原料时，对目标物品一键自动合成**整条配方树**——省略中间步骤（分解木板、合成木棍），直接从原木做出木稿。

**Forge 1.20.1 · 纯客户端** · 仅依赖 Minecraft Forge（EMI/JEI 可选增强）

## 特性

- 🧠 **有界回溯搜索规划器**：从目标递归展开配方树，多配方自动选择、环保护、护栏（256 步/65536 状态/500ms/失败记忆）
- 🖱️ **四条入口**：合成桌内按 `B` ｜ EMI 悬停按 `B` ｜ EMI 配方屏按钮（Mixin 注入标准按钮列）｜ JEI 配方屏按钮
- 🧰 **多网格适配**：原版 3×3 合成台、精妙背包工作台、AE2 终端、RS 合成网格（CraftingGridAdapter 抽象）
- 🌲 **计划预览**：自写层叠配方树（缩放/平移/悬停 tooltip）+ 总耗材汇总，EMI-free 实现
- 🔧 **公网服安全**：全部走标准容器点击包、每 tick 1 个点击、批次间隔可配

## 快速开始

```
1. 丢 autocraft-1.1.1.jar 进 mods/
2. 放 16 个原木进背包，打开合成台
3. 网格摆出木稿 → 按 B → 预览 → 开始合成
```

详见 [USAGE.md](USAGE.md)（完整使用说明）/ [TEST-PLAN.md](TEST-PLAN.md)（验收计划）。

## 构建

```
./gradlew build          # 产物 build/libs/autocraft-1.1.1.jar
```

依赖：Forge 1.20.1-47.4.0 + `libs/` 内的 EMI 1.1.24 / JEI 15.20.0.129 jar（锁定版本，见 build.gradle）。

## 已知问题（v1.1.1）

- **配方树预览偶发"虚线/虚空引用"**：大树或含共享中间产物（如贤者之石类催化剂）时，树枝连线可能穿过空位或间断出现节点。**仅影响预览观感，不影响实际合成执行**。详见 DESIGN-v2.md §13。
